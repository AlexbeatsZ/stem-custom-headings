# 自制标题引用

把以下格式识别为文章内的自制标题：

```md
> **B.O.近似**
```

## 引用语法

```md
[[#-B.O.近似|B.O.近似]]
![[#-B.O.近似]]
[[另一篇笔记#-B.O.近似|B.O.近似]]
```

- `[[#-`：输入时搜索自制标题并插入链接
- `![[#-`：输入时搜索并插入完整段落
- 点击链接跳到原文，悬停可预览
- 同名标题依次使用 `标题`、`标题 1`、`标题 2`；旧的 `标题§2` 仍可解析
- 修改标题名后，Vault 内的 `#-` 链接与嵌入会自动同步
- 自动生成的显示文字会更新，手写的自定义别名保持不变
- 普通的 `[[#Markdown 标题]]` 不受本插件影响

在命令面板中也可使用“插入自制标题引用”和“插入自制标题嵌入”。

## 安装与构建

GitHub Release 提供 Obsidian 可直接安装的 `main.js`、`manifest.json`
与 `styles.css`。源码构建：

```bash
npm ci
npm test
npm run build
```

构建结果位于 `dist/main.js`。
